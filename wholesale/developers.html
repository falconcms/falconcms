For Developers ​

Falcon Wholesale is built on the shop's logic hooks, and exposes hooks of its own so a theme or another plugin can change what it does. Register them in a theme's functions.php or a plugin's service provider. A filter returns its first argument, changed or not.

Who is wholesale, and at what price ​

HookTypeArgumentsUse it to
falcon_wholesale_customer_levelfilter?Level $level, ?User $userMake someone wholesale by another rule, or take it away. Return a Level or null.
falcon_wholesale_pricefilter?float $price, array $contextChange the wholesale price: quantity tiers, a price list per customer, rounding. $context holds post_id, variation_id, level, quantity (the cart line's quantity in the cart), retail (['price', 'sale_price']) and source (variation, product, category, level or null). Return null for the retail price.
falcon_wholesale_category_discountfilterfloat $percent, int $postId, Level $levelChange the category discount (0–100).
falcon_wholesale_tiersfilterarray $tiers, int $postId, Level $levelChange the quantity tiers that apply: each ['level' => int, 'min' => int, 'max' => ?int, 'type' => 'percent'|'price', 'value' => float].
falcon_wholesale_tier_labelfilter?string $label, array $tier, int $postId, int $quantityChange how a line's price tier is written ("20+ pcs · ৳30.00 each").
falcon_wholesale_hidden_price_htmlfilterstring $html, $product, string $context, bool $guestChange what replaces a hidden price ($context price) or buy button (cart).
php
// 5% more off from 50 pieces.
add_falcon_filter('falcon_wholesale_price', function ($price, $context) {
    return $price !== null && $context['quantity'] >= 50 ? $price * 0.95 : $price;
});

Applications and accounts ​

HookTypeArgumentsWhen
falcon_wholesale_application_fieldsaction?WholesaleCustomer $accountInside the application form. Print extra fields here.
falcon_wholesale_application_rulesfilterarray $rules, Request $requestValidation rules for the form. Add your fields' rules.
falcon_wholesale_application_datafilterarray $data, Request $requestWhat is saved. Put extra fields under $data['meta']. They show on the customer screen.
falcon_wholesale_auto_approvefilterbool $approve, WholesaleCustomer $accountApprove some applications automatically (for example a verified BIN).
falcon_wholesale_application_submittedactionWholesaleCustomer $accountAn application was sent or sent again.
falcon_wholesale_customer_approvedactionWholesaleCustomer $accountAn account was approved.
falcon_wholesale_customer_rejectedactionWholesaleCustomer $account, ?string $reasonAn account was rejected or revoked.
falcon_wholesale_customer_level_changedactionWholesaleCustomer $account, ?int $oldLevelIdAn approved customer moved to another level.
php
// Ask for annual volume on the application.
add_falcon_action('falcon_wholesale_application_fields', function () {
    echo '<label>Annual volume <input name="annual_volume" type="number" required></label>';
});
add_falcon_filter('falcon_wholesale_application_rules', fn ($rules) => $rules + ['annual_volume' => 'required|integer|min:0']);
add_falcon_filter('falcon_wholesale_application_data', function ($data, $request) {
    $data['meta'] = ['annual_volume' => (int) $request->input('annual_volume')];
    return $data;
});

Emails ​

Every wholesale email uses one layout (resources/views/emails/layout.blade.php): your Shop email header image, or your logo, or your shop name; your theme's primary colour; and the Shop email footer text. It works in the usual email clients and narrows for phones. A theme can override any email view under falcon-wholesale::emails.*.

In code ​

Changes to an account should go through FalconWholesale\Support\Accounts (apply, approve, reject, setLevel), so the actions above fire and the emails go out. FalconWholesale\Support\Customers::currentLevel() tells you the signed-in shopper's level.

Data ​

TableWhat

wholesale_sales_repsSales reps: user, commission percent, whether they are emailed orders

Levels also hold hidden payment and shipping methods, free shipping from, deposit and spend discounts. Company members hold their approval rules (needs_approval, order_limit), and wholesale customers their tax exemption and sales rep. An order's meta records wholesale_approval, wholesale_deposit, wholesale_tax_exempt and wholesale_rep; the PO number is meta.checkout_fields.po_number.

Variation prices are stored on the variation row: shop_product_variations.meta.falcon_wholesale, keyed by level id. Settings are CMS options named wholesale_*.
